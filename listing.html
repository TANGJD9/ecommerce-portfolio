转化逻辑拆解（面试可讲）① 标题 = 核心关键词前置 + 场景/痛点词 + 差异化卖点 + 规格词，兼顾搜索与点击；② 五点卖点 = 每条都「先给结果、再给证据」，直接回应目标人群痛点；③ 价格 = $19.99 划线价 + 25% 折扣制造「优惠感」，再用 5% 优惠券提高转化；④ 信任 = 星级、评论数、Prime、退换保障逐层消除顾虑。

促销的本质是「用短期让利换排名与评论」，每次促销后都要复盘利润与自然位变化。

🛍️ 宠物慢食益智碗 · 品牌故事（A+ 内容预览）
🐶

狗狗为什么总吐？

进食过快是呕吐、胀气、肥胖的头号元凶。我们的迷宫设计让进食放慢 3 倍，让吃饭回归健康节奏。

🌀

慢食迷宫结构

三层迷宫凸脊 + 错位通道，狗狗需要用舌头和鼻子「工作」才能吃到，天然放慢进食速度。

🫧

强力吸盘底座

3 点式吸盘设计，光滑地面一按即稳，大型犬也掀不翻；吸盘可拆卸，清洗零死角。

🧼

食品级安全材质

BPA-free 食品级硅胶，柔软不伤牙、高温可煮消毒，入口更安心，狗狗舔得放心。

⚖️

容量刻度科学喂食

2.5 杯大容量 + 清晰刻度线，适配 5–60 磅犬种，控制食量、拒绝过度投喂。

📦

开箱即用

食品级包装 + 双语说明书，附赠小型零食勺，到手即可开始「慢食训练」。

🖼️ 场景图示例（品牌氛围感）

场景图让买家「代入画面」：温暖的客厅 + 开心的狗狗 = 我买了也能这样。这是 A/B 测试中胜出的主图方向（详见复盘页）。

📝 A+ 内容写作原则

  • 先讲「用户痛点」，再讲「产品方案」
  • 每个模块只讲一个核心卖点，配一张图
  • 用数字说话：3 倍慢食、2.5 杯、5–60 磅
  • 统一品牌色与视觉，强化品牌记忆
⚠️
可迁移经验这套「痛点→方案→证据」的写法，同样适用于 TikTok Shop 的商品卡、Shopee 的图文详情和独立站的 Landing Page——底层都是「把卖点翻译成用户语言」。
